WHAT I LEARNED TODAY:
- A process = a running program, identified by a unique PID
- STAT column codes: R=Running, S=Sleeping, D=Uninterruptible sleep, Z=Zombie, T=Stopped
- Zombie = process finished but parent hasn't "collected" its exit status yet
- Signals: SIGTERM (15) = graceful stop, SIGKILL (9) = forceful, SIGHUP (1) = reload config
- Rule: always try kill (SIGTERM) before kill -9 (SIGKILL) — force-kill skips cleanup
- Background jobs (&) die when terminal closes, UNLESS run with nohup
- systemctl manages services (start/stop/restart/status) — the modern way to control daemons

COMMANDS I PRACTICED:

[ ] pgrep / pgrep -l
[ ] kill / kill -9
