WHAT I LEARNED TODAY:
- Linux = Kernel (brain) + Shell (translator) + Distro (full package)
- Everything in Linux is treated as a file — even hardware and processes
- Kali Linux is Debian-based, built specifically for security/pentesting work
- The Linux filesystem is ONE single tree starting from root "/"
  - /etc      = system configuration files
  - /home     = user personal folders
  - /var/log  = system logs
  - /proc     = live kernel/process data (not real files on disk)
- "Available" memory (not "free") is the number that actually matters
  when checking how much RAM is left to use
